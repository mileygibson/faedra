# Faedra: Hartshollow

A small, playable forest adventure that runs directly in a browser. The game is self-contained in `index.html`; no build tools or dependencies are required.

## Play

Open `index.html` in a browser, or publish the repository with GitHub Pages.

## Publish with GitHub Pages

1. In the repository, open **Settings** → **Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Choose the `main` branch and `/ (root)`, then select **Save**.
4. Open the Pages URL shown in Settings after the deployment finishes.

To edit the game on GitHub, open `index.html`, select the pencil icon, make your changes, and commit them to `main`. Pages will publish the update automatically.

## Controls

- **Move:** WASD or arrow keys; use the on-screen directional pad on a phone.
- **Jump:** Space or the on-screen **Jump** button.
- **Attack:** J or the on-screen star button.
- **Interact:** E or the on-screen **Use** button.

Find the three lost lights, then return to the old shrine in the eastern clearing.
